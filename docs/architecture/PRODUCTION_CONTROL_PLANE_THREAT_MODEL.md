# 生产控制面威胁模型（Proposed）

## 状态与效力

- 状态：**Proposed**（2026-09-24）。由主控 Agent 提出，待项目负责人确认。
- 适用范围：ADR-010 定义的未来 R0 平台控制面——平台 API、模型网关、预算许可、任务/提交元数据与教师 Web 后端。
- 不适用于：学生本机 Code Workspace / Agent Node（属 ADR-002 与 Foundation Spike 的后续安全研究）。
- 不代表：任何威胁已被缓解、任何控制已实现、或任何安全验证已经完成。本文只定义需要关闭的安全前提。

## 1. 资产

| ID | 资产 | 说明 |
| --- | --- | --- |
| A1 | 学校模型凭据 | DeepSeek 学校统一凭据及其托管密钥服务中的存储形态。最高敏感级。 |
| A2 | 身份与租户数据 | 学校、教师、学生账号标识与角色关系。 |
| A3 | 任务与提交元数据 | 任务模板、版本、提交包、教师反馈、状态迁移。 |
| A4 | 过程事件 | 平台内最小应用事件与版本信息（append-only）。 |
| A5 | 预算额度与用量 | 100 元/月硬上限的预留、结算、释放与对账记录。 |
| A6 | 审计与运行日志 | 访问、变更、失败与安全事件记录。 |
| A7 | 控制面服务身份 | 控制面向密钥服务、数据库与供应商 API 证明自身身份的能力。 |
| A8 | 主机与网络入口 | ECS 主机、22 端口管理入口、未来业务入口与 TLS 终止点。 |

## 2. 角色

| 角色 | 信任级别 | 说明 |
| --- | --- | --- |
| 学生 | 低 | 只使用学校已开放模型档位；不得看到 provider、model ID、endpoint、预算或 Key。 |
| 教师 | 中 | 可创建任务、复核、请求补正；可选 BYOK 仅经服务端凭据引用。 |
| 学校管理员 | 中高 | 未来管理学校档位、凭据引用、课程范围与预算。 |
| 平台运维 | 高 | 可访问主机与部署配置；受最小权限与审计约束。 |
| 项目负责人 | 决策 | 批准供应商、费用、保留与部署。 |
| 外部攻击者 | 不可信 | 互联网可达面内的任意主体。 |
| 模型供应商 | 外部 | 接收冻结合成文本的第三方服务。 |

## 3. 信任边界

| ID | 边界 | 跨越内容 |
| --- | --- | --- |
| TB1 | 学生/教师客户端 ↔ 控制面 API | 认证凭据、任务与提交内容 |
| TB2 | 控制面 ↔ 托管密钥服务 | 短时密钥解析结果 |
| TB3 | 控制面 ↔ 模型供应商 API | 冻结合成任务文本 |
| TB4 | 控制面 ↔ 关系数据库 | 身份、任务、提交、预算、审计数据 |
| TB5 | 控制面 ↔ 日志与审计存储 | 脱敏后事件 |
| TB6 | 运维 ↔ ECS 主机 | SSH、部署配置、密钥服务访问策略 |
| TB7 | 控制面 ↔ 研究导出 | 去标识化后的受限数据集 |

## 4. 威胁、缓解前提与残余风险

| ID | 威胁 | 影响资产 | 需要的缓解前提 | 残余风险 | 关联前置项 |
| --- | --- | --- | --- | --- | --- |
| T-01 | 模型凭据泄露到 Git、`.env`、数据库、客户端、日志、Artifact 或聊天 | A1 | 仅经托管密钥服务解析短时结果；静态扫描与日志负向测试 | 运维误操作与内存转储仍可能泄露 | PCP-11、PCP-12、PCP-13 |
| T-02 | 学生越权读取其他租户、教师或其他学生的数据 | A2、A3 | 真实身份、角色授权与租户隔离，服务端强制校验 | 授权模型配置错误 | PCP-01、PCP-02、PCP-03 |
| T-03 | 并发或重启后突破 100 元/月上限 | A5 | 持久、原子、可审计账本，事务级预留 | 供应商侧价格变更导致估算偏差 | PCP-14、PCP-15、PCP-16 |
| T-04 | 过度收集学生数据（全桌面、无关字段、设备信息） | A2、A3 | 字段级最小化清单与拒绝规则 | 需求蔓延导致字段回增 | PCP-05 |
| T-05 | 运营数据未经授权被用于研究 | A3、A4 | 运营/研究平面分离、独立授权与去标识化导出 | 内部流程绕过 | PCP-06、PCP-07 |
| T-06 | 网络入口扩大（误开 80/443/数据库端口或管理面暴露） | A8 | 入口最小化清单、默认拒绝、变更审计 | 临时排障留下的规则 | PCP-21、PCP-22、PCP-24 |
| T-07 | 主机被入侵后凭据被读取或横向移动 | A1、A7、A8 | 服务运行身份、最小权限、主机加固、出站限制 | 零日与提权漏洞 | PCP-23、PCP-26 |
| T-08 | 日志或错误信息含个人信息或凭据 | A6、A2 | 日志分类、脱敏规则、错误路径负向测试 | 异常堆栈泄露 | PCP-18、PCP-13 |
| T-09 | 模型不可用时静默切换到其他供应商 | A3、A5 | 显式 `MODEL_UNAVAILABLE`、固定降级、供应商白名单 | 配置漂移 | PCP-17、PCP-13 |
| T-10 | 学生代码或本地模型在 ECS 上被执行 | A7、A8 | 控制面不含执行器；进程与部署审计 | 误装执行组件 | PCP-23、PCP-25 |
| T-11 | 备份泄露或不可恢复导致数据暴露或证据断裂 | A3、A4、A5 | 加密备份、访问控制、恢复演练与 RPO/RTO | 备份介质管理 | PCP-10 |
| T-12 | 控制面服务身份被冒用访问密钥服务或数据库 | A1、A7 | 工作负载身份绑定、短时凭据、撤销路径 | 身份配置错误 | PCP-04、PCP-12 |
| T-13 | 审计日志被删除或篡改，导致事件不可追溯 | A6 | append-only 审计、独立保留、访问者最小化 | 高权限运维仍可操作 | PCP-19、PCP-20 |

## 5. 不在本模型范围

- 学生本机 Workspace、文件读写、进程树与符号链接攻击（ADR-002、Foundation Spike）。
- 外部 AI 检测、作弊判定、学生能力推断（项目禁止事项）。
- DDoS 容量规划、WAF 规则、合规认证（属独立决策）。
- 真实学生数据与真实课堂场景（尚未授权）。

## 6. 使用规则

1. 本模型为 Proposed；任何“已缓解”结论必须由清单中的可复核证据支持，不能由本文的表格本身支持。
2. 新增威胁或新增平台内信号前，必须先在本表增加一行，并同时补充对应的“事实—允许动作—禁止推断”记录。
3. 本模型不得被引用为安全验证完成、合规达标或可部署的证据。
