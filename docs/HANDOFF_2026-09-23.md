## 项目概述

SkillShift Lab 是面向高职大数据技术方向的“人机协作能力训练”项目。它关注的不是让学生单纯使用 AI 生成代码，而是让学生在允许 Agent 协作的情况下，仍能完成需求理解、假设控制、结果核验、错误诊断、修正和最终责任承担。

项目提出两种任务模式：

- **Foundation Track**：限制或不使用 Agent，观察基础技能和独立判断。
- **Agent Track**：允许 Agent 协作，但提高任务要求，要求保留假设、核验、纠错和接管证据。

长期设想中的产品会包含学生工作区、教师查看界面、任务执行环境、确定性核验器和报告能力。当前尚未实现这些正式前后端产品功能。
