# ADR-009 学校合成探针预算许可

## Status

Accepted（2026-09-24；仅限本地、合成、默认拒绝的预算许可契约）。

## Context

项目负责人已授权 DeepSeek 首轮合成探针的学校费用硬上限为 100 元/月。ADR-008 要求在请求前取得预算许可；否则运行时必须拒绝。

当前没有学校身份、账户、数据库、账单或供应商用量回调。因此本决策不能实现真实财务核算；它只建立一个可测试的、请求前保守预留额度的本地接缝，防止未来运行时在未明确许可的情况下出网。

## Decision

1. 月度硬上限固定为 10,000 分（100 元），不能由课程、教师、学生、请求或前端输入提高。
2. `SchoolSyntheticProbePolicy` 默认 `enabled=false`。未显式启用的学校范围不会解析凭据或调用传输层。
3. `SchoolMonthlySyntheticBudgetPermit` 只允许 DeepSeek、学校统一管理、`synthetic-task-only` 与 `deepseek-flash` 的受限请求。每次许可先预留一个服务器配置的保守金额；超过上限拒绝。
4. 预留计数使用进程内锁保护，仅用于本地契约测试。它不是跨进程/跨服务器原子账本、实际收费对账或学校身份实现。
5. 未来真实运行时必须以持久、原子、可审计的预算账本替换该实现，并记录价格版本、预留、实际用量、失败释放/结算、告警和月度重置；在替换前不得进行真实调用。

## Consequences

- 可证明并发请求不会超过 100 元的预留上限，且默认状态不触发凭据或网络。
- 不可声称已完成真实费用扣减、供应商账单核对、额度刷新或管理员 UI。
