# R0 Agent-first 交付路径决策

## 状态与效力

- 状态：**Accepted**（项目负责人于 2026-09-24 确认）。
- 范围说明：2026-09-25 项目负责人确认项目型 Agent 工作空间方向，见 `R0_PROJECT_AGENT_WORKSPACE_DECISION.md`。本记录中的纯文本、无本机执行范围继续定义已验证的确定性流程 Harness；目标产品的代码编辑体验由新决策和规格定义，代码执行仍未开放。

- 优先级：本记录在“R0 首条闭环必须先完成本机受限执行 Foundation Spike”的问题上，覆盖较早的 `HANDOFF_R0_CONTINUATION_2026-09-24.md`、`specs/R0-FOUNDATION-SPIKE/README.md` 和 ADR-002 表述；其余安全、隐私、研究与禁止事项仍然有效。

## 1. 已确认的产品判断

SkillShift 的首要产品不是“可在学生电脑上自动执行任意代码的 Agent”。它首先是一个面向教学任务的通用教育 Agent：教师创建明确任务，学生与 Agent 协作完成学习活动并承担验证、解释、纠错或补正责任，教师据任务内可观察事实给出反馈。

这里的“通用”指可服务于不同教学任务类型；不指拥有任意宿主机权限、任意 Shell、任意网络、全桌面观察或自动代替学生操作电脑。

## 2. R0 首条闭环

首条闭环固定为：

```text
教师创建模板任务
→ 学生阅读任务并与教育 Agent 协作
→ 学生提交任务要求的验证/解释/补正内容
→ 教师查看最小提交与可解释状态
→ 教师认可或请求说明/补正
→ 学生回应并重新提交
```

第一条闭环只处理平台内的任务文本、Agent 对话、学生主动提交的文本或任务允许的 Artifact 元数据，以及教师反馈。它不读取、写入或运行学生本机项目；不扫描桌面、浏览器、私人文件或外部 AI 使用情况。

学生使用个人浏览器访问互联网或课程网站不受本项目禁止。此处“Agent 不联网/不使用网络工具”只描述 Agent 的工具权限；Foundation Spike 的操作系统网络隔离也只针对未来可选的代码执行进程，不是学生上网限制或课程网络政策。当前平台内 Agent 不会替学生浏览网站，也不会采集或判断其外部浏览活动。

## 3. 本机 Code Workspace 的新位置

`LocalRestrictedProcessProvider`、Windows Job Object、AppContainer、网络策略、符号链接防护和进程树停止仍是有价值的**后续 Evidence Adapter / 本机代码工具**研究。既有 Foundation Spike 的 PARTIAL/FAIL 结论必须保留，且在将来引入 Agent 本机读写、命令运行、依赖安装或项目执行前，仍须以相应安全证据关闭。

它们不再阻塞本决策第 2 节所定义的无本机自动执行教学闭环。不得把这项调整误写成“安全问题已解决”。

## 4. 仍然有效的边界

- 不判定作弊、外部 AI 使用、学生真实能力或 AI 替代率。
- 不自动生成成绩或能力画像。
- 不处理真实学生隐私数据、模型 API Key、密码、私钥或 AccessKey。
- 不自动部署、推送或让现有 ECS 运行任意学生代码。
- 真实模型供应商、数据路径、成本、保留期限与真实学生试用须另行决策；模型密钥绝不进入学生客户端。

## 5. 分阶段门槛

| Gate | 目标 | 最小证据 | 禁止跨越 |
| --- | --- | --- | --- |
| A | 合成 Agent-first 闭环 | 一项冻结合成任务、确定性 Agent 适配器、状态转换、提交/反馈/补正测试和 Artifact。 | 真实模型、真实学生、部署。 |
| B | 模型与数据路线 | 独立 ADR、供应商/成本/数据路径决定，以及不含真实学生数据的集成验证。 | 未经决定向第三方发送学生数据。 |
| C | 教师流程验证 | 合成案例与明确范围的教师可用性反馈。 | 学习效果、课堂规模或研究结论。 |
| D | 可选本机 Code Workspace | Foundation Spike 与独立安全规格的适用项均有客观证据。 | 用未验证 Provider 运行外来或学生项目。 |
