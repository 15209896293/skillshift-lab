# R0 项目型 Agent 工作空间产品决策

## 状态与效力

- 状态：**Accepted**（项目负责人于 2026-09-25 选择方案 B）。
- 适用范围：SkillShift Studio 首个面向用户的项目型 Agent 产品切片及其教师端、学生端和控制面规划。
- 本决策只确认产品切片方向，不代表代码执行安全、真实模型接入、真实用户验证、生产身份、数据服务或部署已完成/获准。
- 本决策对先前“首条产品闭环完全不处理项目代码”的范围作出有限修订；原确定性合成流程仍保留为流程测试 Harness。其余研究、隐私、安全和部署边界继续有效。

## 1. 产品目标

SkillShift Studio 面向职业教育任务，为教师提供创建 AI 协作项目、查看任务相关交付与证据、给出反馈和补正的工作流；为学生提供在任务上下文中使用 Agent 完成项目的工作空间。项目价值不在于通用 Agent 能力超过 Codex/Cursor，而在于把职业任务、Agent 协作、学生责任和教师指导组织成可完成、可复核的教学过程。

首批用户假设是高职大数据、计算机、软件方向的教师/导师与学生；Python + CSV 是第一个 Golden Path 候选，不限制未来任务类型。教师低负担和学生实际价值仍须验证，不能当作已证实需求。

## 2. 首个产品切片

```text
教师 Web：定义任务、允许的 Agent 协作、交付和验证责任
    → 学生工作空间：在任务上下文中使用 Agent 处理项目材料/代码
    → 学生说明、验证并提交项目结果
    → 教师查看任务相关提交与过程事实，给出反馈/补正
```

教师端与学生端是独立工作空间和角色入口，不是单页里的角色标签。后台控制面承载任务/版本、访问授权、Agent/模型网关、事件与提交元数据、预算和复核状态。

## 3. 代码能力与安全界线

项目型学生工作空间应支持代码任务的项目上下文和代码编辑体验，例如文件导航、代码编辑、Agent 对话/计划、修改差异、学生确认/拒绝/接管及任务要求的验证说明。这是目标产品体验，不代表当前原型已具备。

**代码执行单独过安全 Gate。** 在执行 Provider、路径/链接边界、网络限制、进程树终止、资源限制、清理和失败恢复得到独立客观证据前：

- 不运行外来或真实学生项目；
- 不把现有 ECS 控制面或现有 `LocalRestrictedProcessProvider` 当作安全执行器；
- 不允许 Agent 自主执行 Shell、依赖安装或不受限网络工具；
- 设计原型可以使用明确标记的合成示例、静态输出或模拟运行结果，但不得呈现为真实运行证据。

桌面 Studio/本机节点与浏览器工作空间/独立远端执行服务仍是待评估形态；本决策不选择实现路线。学生正常使用个人浏览器和互联网不受限制；平台 Agent 的网络工具权限是独立配置，不观察外部活动。

## 4. Agent 与模型边界

- Agent 应围绕任务与项目材料回答、解释、提出计划或修改建议；涉及项目变更时，保留学生检查、确认、拒绝和接管能力。
- OpenAI API 路线已否决。国产模型服务端网关、DeepSeek 首个供应商方向和学生无 Key 边界按 ADR-006 至 ADR-009 保留；不代表真实模型调用现已授权。
- 真实模型、真实 Key、第三方数据流、持久预算/对账与生产身份必须通过现有 Gate B / PCP 门禁；当前确定性适配器只能称流程模拟。
- 降级必须可见；不得把固定脚本回答伪装成模型能力。

## 5. 开发与验证顺序

1. 冻结一个合成 Python + CSV 项目任务及教师/学生各自的目标、动作、责任和可观察结果。
2. 先设计并实现独立教师 Web 工作流，使用合成数据验证任务创建、发布预览、复核与补正。
3. 再设计并实现独立学生项目工作空间，呈现任务、项目材料/代码、Agent、差异检查和提交；在安全 Gate 前不运行项目。
4. 在前端实现前先明确共享领域对象与 API/事件契约；在两端原型可用后实现最小后端纵向切片，将两端接通。后端 UI 可后置，但架构契约、权限和数据边界不能后置。
5. 模型调用、代码执行、真实身份/学生数据与部署均按各自 Gate 单独进入，不得因为本决策而合并放行。

前两端原型不是生产产品，也不能证明用户价值；后续必须通过获批的教师/学生反馈验证“易布置、真能做、可理解、可补正”。

## 6. 非目标与持续保护

- 不建设完整 LMS、成绩册、自动评分、能力画像、外部 AI 检测或全桌面监控。
- 不将日志、粘贴、过程缺失、相似度或 Agent 动作解释为作弊、努力或能力结论。
- 不把项目运营数据自动转为研究数据。
- 不让控制面 ECS 运行任意学生代码。
- 不自动连接服务器、部署、提交、推送、删除或清理。
