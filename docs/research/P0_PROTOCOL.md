# P0 Research Protocol

## Goal

Before full MVP development, validate whether SkillShift is solving a real problem and whether the first product direction is worth building.

## P0-A Traditional Task Agent Impact Audit

Collect 10 to 20 real traditional higher vocational Big Data Technology training tasks.

For each task, record:

- source,
- task type,
- original learning goal,
- expected student output,
- environment,
- whether a current agent can complete it,
- time used,
- human intervention required,
- common failure mode,
- what the original task still measures,
- whether it can become a Foundation / Agent paired task.

Do not calculate or publish AI replacement rate.

## P0-B Needs Validation

Interview or survey students and teachers.

Goal:

- verify whether students want structured professional agent practice,
- verify whether teachers recognize the problem,
- find objections and failure cases.

## P0-C Dual-Track Task Reconstruction

Rebuild 3 traditional tasks into:

- Foundation Track,
- Agent Track,
- transfer or reflection layer,
- evidence contract,
- hidden verifier idea.

## P0-D Vertical Slice

Create one small end-to-end product slice only after enough P0-A/B/C evidence exists.

## P0-E Small Pilot

Run a voluntary after-class pilot with 5 to 20 students.

Validate:

- willingness to use,
- task comprehension,
- agent collaboration behavior,
- event recording,
- product attractiveness,
- privacy and stability issues.
