# SkillShift Lab Research Workflow

## Purpose

Research work must not live only in chat history.

Every research task should leave behind:

- a question,
- a method,
- evidence,
- limitations,
- a conclusion,
- a product or research decision.

## Research Flow

Question -> Assumption -> Method -> Evidence -> Analysis -> Limitations -> Conclusion -> Decision

## Required Output

Each research task should produce:

- Markdown report,
- raw data location,
- analysis script location, if any,
- evidence summary,
- limitations,
- impact on product decisions.

## Boundaries

- Do not output AI replacement rate.
- Do not overstate pilot results.
- Do not use unverified research metrics for student grading.
- Do not merge research identity data with operational identity data without explicit governance.
