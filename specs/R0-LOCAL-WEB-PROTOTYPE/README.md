# R0-LOCAL-WEB-PROTOTYPE：教师与学生本机合成网页原型

## 状态

- Task ID：`R0-LOCAL-WEB-PROTOTYPE-001`
- 类型：FEATURE / Gate A 产品交互扩展
- 状态：**Implemented / Verified（2026-09-24；仅限本机、合成、确定性、无外部服务范围）**。
- 上游：`docs/product/R0_AGENT_FIRST_DELIVERY_DECISION.md`、`docs/product/REQUIREMENTS_SPEC.md`、ADR-004、ADR-011。

## 目标

在不改变 Gate A 的合成、确定性和无本机自动执行边界的前提下，给教师和学生各提供一个可操作网页视图，并用本机 JSON API 演示完整状态路径：创建任务、开始、任务内引导、提交、请求说明或补正、重提、认可与最小提交包查看。

本任务验证“前端操作能正确驱动既有领域状态机”，不验证教学效果、真实学生体验、认证安全、真实模型、费用、服务器部署或本机代码执行。

## 允许范围

- `apps/agent-first/` 下的本机标准库 API、静态 HTML/CSS/JavaScript 和启动入口；
- 复用 `EducationWorkflow`、固定字段结构的合成模板（标题/目标/学生责任/提交要求文字可编辑）与确定性引导适配器；
- 进程内、重启即清空的合成任务存储；
- API、静态资源和完整状态路径的单元/集成测试；
- 对应 Artifact 与当前状态文档。

## 禁止范围

- 真实账号、个人信息、课程/班级、数据库、Cookie、生产认证或多租户；
- 真实模型调用、模型 Key、环境变量密钥、外网请求、供应商 SDK、RAG、工具或联网搜索；
- ECS 连接、端口开放、部署、域名、HTTPS、Docker、持久预算账本或实际费用；
- 本机文件读写、Shell、学生代码执行、浏览器自动化、监控、评分、作弊/能力/外部 AI 推断；
- 修改 Foundation Spike、历史研究材料或已有模型运行时契约。

## 交付与接口

| 部分 | 最小交付 |
| --- | --- |
| 教师视图 | 创建固定任务、查看状态和学生提交、填写理由并选择认可/请求说明/请求补正/环境问题。 |
| 学生视图 | 开始任务、获取确定性引导、提交验证/解释/纠错/补正内容、查看教师反馈。 |
| 本机 API | 健康检查、任务创建/读取、开始、引导、提交、复核、Manifest；统一 JSON 成功或错误响应。 |
| 数据边界 | 仅 `teacher-demo`、`student-demo` 与冻结任务；全部进程内，重启清空。 |

## 验收

| ID | 条件 | 最小证据 |
| --- | --- | --- |
| LWP-01 | 教师可在页面创建一个固定合成任务，学生可读取任务状态。 | API/静态资源测试。 |
| LWP-02 | 学生可开始任务、请求确定性引导并提交任务关联响应。 | 集成测试。 |
| LWP-03 | 教师可请求说明、补正、标记环境问题或认可；理由不足和角色越权被拒绝。 | 正/负向 API 测试。 |
| LWP-04 | 学生补交后，教师认可可生成 `CLOSED` 的最小 Manifest。 | 端到端状态机测试。 |
| LWP-05 | API 与前端不使用外部脚本、外网、真实凭据、真实身份、评分或禁止推断文本。 | 静态边界测试与代码审阅。 |
| LWP-06 | 服务启动入口默认只绑定回环地址，且测试不启动长期服务。 | 启动配置/WSGI 测试。 |
| LWP-07 | 浏览器刷新后可从进程内列表恢复最近的合成任务；重启服务仍清空状态。 | API 列表与前端初始化契约测试。 |
| LWP-08 | 教师可在固定结构上编辑四个有界文本字段；创建后教师/学生视图、刷新恢复与提交 Manifest 引用一致。 | `R0-TEACHER-TASK-AUTHORING-001` 测试与浏览器 Artifact。 |

## 停止条件

出现真实学生数据、账号/角色体系、数据持久化、真实模型、凭据、外网、部署、ECS 连接或本机代码操作需求时，停止在本规格范围内推进，创建独立 ADR 和可验证规格。

## 验证计划

1. 编译检查；
2. 本规格 API/页面测试；
3. 既有 Gate A 与 Gate B 相关测试回归；
4. 审阅 `git diff --check`、静态资源和 Artifact；
5. 不启动长期开发服务器，不执行真实网络调用。
