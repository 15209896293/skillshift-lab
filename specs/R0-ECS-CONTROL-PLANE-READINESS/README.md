# R0-ECS-CONTROL-PLANE-READINESS：ECS 控制面就绪规格

## 状态

- Task ID：`R0-ECS-CONTROL-PLANE-READINESS-001`
- 类型：DEV_OS / Gate B 部署就绪
- 状态：**Planned（未部署）**。
- 上游：ADR-010、ADR-008、ADR-009。

## 目标

将现有 ECS 准备为只负责平台 API、模型网关、预算和元数据的控制面；它不得运行学生代码或本地大模型。

## 实施顺序

1. 在本地完成 API、角色、凭据引用和持久预算账本的契约测试。
2. 配置服务器服务身份与托管密钥服务；密钥不得出现在本地仓库或聊天。
3. 配置最小网络入口、TLS、服务账户、持久数据库、日志脱敏、备份和预算告警。
4. 只对冻结合成任务执行一次已授权的 DeepSeek 探针，记录费用/用量摘要而非 Key 或原文。
5. 通过失败、撤销、预算、恢复和审计验证后，再提出下一 Gate。

## 禁止范围

- 任意学生代码、本机 Workspace、Docker 沙箱、本地大模型/GPU、真实学生数据、正式课堂、自动评分、Cheating/能力判断；
- 在没有托管密钥、持久预算账本、TLS、身份授权和合成探针授权时部署或开放业务端口。

## 验收

| ID | 条件 | 最小证据 |
| --- | --- | --- |
| ECP-01 | ECS 只运行控制面服务，无学生执行器或模型进程。 | 部署清单与进程审计。 |
| ECP-02 | Key 只经托管密钥服务解析，静态扫描、日志和错误不含 Key。 | 密钥/日志负向测试。 |
| ECP-03 | 持久账本在并发与重启后仍不突破 100 元月度上限。 | 集成/恢复测试。 |
| ECP-04 | 合成探针只发冻结文本，工具/联网搜索关闭，费用和失败可审计。 | 一次有界探针记录。 |

## 停止条件

任何真实学生数据、学生代码、GPU 本地模型、非合成任务、无密钥服务、无预算账本或未知网络入口需求，均停止部署并回到独立决策。
