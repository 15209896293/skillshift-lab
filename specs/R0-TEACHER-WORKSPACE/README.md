# R0 教师任务工作台（首个前端）

## 状态

- Task ID：`R0-TEACHER-WORKSPACE-001`
- 类型：FEATURE / FRONTEND PROTOTYPE
- 状态：Ready for bounded synthetic implementation。
- 上游：`docs/product/R0_PROJECT_AGENT_WORKSPACE_DECISION.md`、`specs/R0-PROJECT-AGENT-WORKSPACE/README.md`、`docs/product/TEACHER_ASSIGNMENT_REVIEW_REMIDIATION_WORKFLOW.md`。
- Gate：产品 UI 原型阶段；不是生产教师系统，也不验证真实教师需求。

## 目标

建立一个与学生工作区概念分离的教师端前端原型，帮助教师理解/检查：如何用少量信息创建一个允许 Agent 协作的职业项目任务，以及学生提交后如何基于任务事实复核、反馈和要求补正。

代表任务：合成 Python + CSV 数据一致性检查。不得称作本地学校历史任务。

## 允许范围

- 独立教师入口，不再以同页角色切换作为最终教师产品结构；
- 教师首页/任务列表的轻量原型；
- 单项任务编辑器：标题、目标、起始项目、学生责任、提交要求和协作模式；
- 学生工作区只读预览图景，明确是预览而非已实现学生应用；
- 复核队列和单提交复核：产物摘要、任务相关验证/说明、有限事件时间线、教师反馈与补正操作；
- 合成固定数据、浏览器端或本机内存交互；必要时使用现有项目轻量网页方式，不引入未经批准的云服务。
- 可复核浏览器操作、测试和报告 Artifact。

## 禁止范围

- 真实账号、班级、教师/学生个人信息、真实作业或文件上传；
- 真实模型/API Key、OpenAI API、ECS/外网或部署；
- 自动评分、排名、作弊/外部 AI 检测、能力判断、监控配置；
- 伪装为真实学生提交、真实 Agent 运行、代码执行或安全沙箱；
- 把本原型扩成完整 LMS、管理后台、生产身份/数据库或学生端实现。

## 验收条件

| ID | 条件 | 最小证据 |
| --- | --- | --- |
| TW-01 | 教师入口视觉/信息架构与学生角色明确分离 | 页面路由/入口及浏览器证据 |
| TW-02 | 可编辑任务目标、学生责任、提交要求和协作模式，并预览学生任务视图 | 可复现交互 + 测试 |
| TW-03 | 能查看一个合成提交的产物/说明和有来源的任务内证据 | 页面状态/浏览器证据 |

| TW-06 | 刷新/失败/无提交状态明确，不伪造持久化或后端已连接 | 测试与页面说明 |

## 停止条件

需要教师真实身份、真实班级/数据、附件上传、后台持久保存、真实模型、计费、部署或真实用户招募时，停止并另立规格/决策。教师端原型通过只说明界面流程可运行，不能声称低负担已得到教师验证。
