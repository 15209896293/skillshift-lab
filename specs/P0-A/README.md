# P0-A Research Spec

## Title

Higher Vocational Big Data Technology Traditional Training Task Agent Impact Audit

## Type

RESEARCH

## Status

Draft

## Goal

Collect 10 to 20 real traditional higher vocational Big Data Technology training tasks and audit how current agents affect them.

The goal is not to prove that AI replaces students.

The goal is to understand which traditional tasks still measure foundation ability, which are compressed by agent use, and which can be rebuilt into SkillShift dual-track tasks.

## Research Question

When current agents are allowed to help with traditional Big Data Technology training tasks, what changes in completion path, time, failure mode, human intervention, and assessment value?

## Inputs Needed

- Real traditional task descriptions.
- Original expected outputs.
- Original scoring or acceptance rules, if available.
- Required software or data.
- Agent run records.
- Human observation notes.

## Method

For each task:

1. Record original task metadata.
2. Run the task with a realistic agent-assisted workflow.
3. Record time, interventions, agent failures, and verification steps.
4. Identify what the task still measures.
5. Decide whether it is a candidate for Foundation / Agent paired redesign.

## Forbidden Claims

- Do not calculate AI replacement rate.
- Do not infer whole-major employability.
- Do not claim broad education conclusions from small samples.
- Do not use agent output as final proof.

## Evidence Required

For each audited task:

- source or file path,
- run notes,
- outputs,
- verification result,
- failure examples,
- human intervention record,
- conclusion and limitation.

## Acceptance Criteria

- AC1: At least 10 real traditional tasks are recorded, or the report explains why fewer were available.
- AC2: Each task has original goal, environment, expected output, and audit notes.
- AC3: Each task has a clear agent impact classification.
- AC4: The report lists failure modes and human intervention points.
- AC5: The report avoids AI replacement rate language.
- AC6: At least 3 candidate tasks are recommended for dual-track reconstruction, if evidence supports them.

## Outputs

- P0-A audit report.
- Raw task inventory.
- Agent run evidence.
- Recommendation list for P0-C.
