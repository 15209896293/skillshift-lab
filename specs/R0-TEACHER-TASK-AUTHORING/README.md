# R0-TEACHER-TASK-AUTHORING：本机合成任务文字配置

- Task ID：`R0-TEACHER-TASK-AUTHORING-001`
- 类型：FEATURE / 合成产品工作流
- 状态：**Implemented / Verified（仅限本机固定合成角色、进程内存储、确定性引导）**。
- Gate：Gate A；Gate B 和生产控制面仍为 PARTIAL。
- 上游：`docs/product/REQUIREMENTS_SPEC.md` AC-R0-01、`specs/R0-AGENT-FIRST-VERTICAL-SLICE/README.md` AF-01、`specs/R0-LOCAL-WEB-PROTOTYPE/README.md`。

## 目标

让教师在冻结示例上快速调整任务标题、目标、学生责任和提交要求，并让这些字段贯穿学生视图、任务内引导输入和提交 Manifest。此步骤让原型能测试“创建任务”，而不只是点击创建固定样例。

它不证明教师实际低负担，仍需后续合成可用性演练和获批的教师验证。

## 允许范围

- 教师网页编辑 4 个有长度上限的文本字段；表单预填冻结合成示例。
- 协作模式继续固定为 `引导需确认`，不宣称已实现不同模式策略。
- 任务只留在本机进程内，学生仍为固定合成角色；刷新恢复行为沿用现有最近任务逻辑。
- 学生查看完整任务字段；任务标题和目标可进入现有任务内引导上下文；Manifest 保留任务 ID/版本和已提交事实，不保留不必要的额外模型账单信息。
- 字段长度和角色授权的正负向测试，以及短时本机浏览器验收。

## 禁止范围

- 真实教师、学生、身份、班级、课程资料、作业或研究数据；
- 文件上传、URL 抓取、浏览器工具、外部网络、真实模型调用或密钥；
- 评分、分班、监控公式、作弊/能力推断；
- 数据库持久化、ECS、登录、权限系统、部署或跨用户隔离；
- 任意任务模板管理、批量任务、课程/班级管理。
