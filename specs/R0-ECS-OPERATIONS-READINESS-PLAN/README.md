## 目标

为 ECS 控制面准备三项可执行的上线前运维方案：服务以最小权限运行、发布可以回退、故障可监测和响应。把每项方案需要的实机证据与仍需决定的事项列清楚。

## 允许范围

- 只读审阅当前产品/架构/安全/部署 ADR 和就绪清单；
- 形成 Proposed 运维计划、验证清单、故障情景和责任边界；
- 更新就绪清单与项目状态，只登记“计划已形成”，不关闭 PCP 项；
- 本地文件检查、哈希与 `git diff --check`。

## 禁止范围

- 连接或操作 ECS；修改防火墙、安全组、SSH、服务、数据库或网络；
- 安装软件、创建账户或 systemd 服务、开放端口、申请域名/TLS、部署或回滚；
- 使用真实密钥、真实学生数据、真实模型调用或费用；
- 把 Proposed 服务加固片段、部署步骤或监控阈值说成已验证或已批准；
- 将 ECS 用作任意学生代码、通用 Shell、浏览器自动化或本机执行器。
