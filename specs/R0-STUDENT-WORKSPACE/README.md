# R0 学生项目工作空间（合成原型）

- Task ID：`R0-STUDENT-WORKSPACE-001`
- 类型：FEATURE / FRONTEND PROTOTYPE
- 状态：Ready for bounded synthetic implementation
- 上游：`docs/product/R0_PROJECT_AGENT_WORKSPACE_DECISION.md`、`specs/R0-PROJECT-AGENT-WORKSPACE/README.md`
- Gate：产品 UI 原型；不证明真实 Agent、用户需求或安全执行能力。

## 目标

提供独立学生入口，围绕一个固定合成 Python + CSV 项目呈现任务、文件、可编辑代码、Agent 建议、差异审阅、人类决策和提交说明。学生的个人浏览器与互联网使用不受限制；本原型没有联网工具，也不监控浏览活动。

## 允许范围

- 独立学生 Web 界面，不含教师/学生角色切换。
- 固定合成任务说明与学生责任。
- 文件导航、浏览器内编辑器、Agent 对话占位、静态修改建议与差异。
- 学生接受、拒绝建议、接管编辑和提交任务相关验证说明。
- 明确说明一切只在当前页面内存演示，无账号、持久化或服务端。
- 运行入口可见但必须禁用，准确解释代码执行 Gate 未开放。

## 禁止范围

- 真实学生、教师、班级、文件、代码或研究数据。
- 真实模型/API、密钥、ECS、服务器端、网络搜索和代码执行。
- 伪造 Agent 调用、代码运行结果、测试结果或已保存/已提交事实。
- Agent 自动写入文件、运行 Shell、安装依赖或连接外部工具。
- 作弊、能力、努力或学习效果推断。

## 验收标准

| ID | 条件 | 证据 |
| --- | --- | --- |
| SW-01 | 独立学生工作区入口及合成边界显著 | 浏览器页面与路由 |
| SW-02 | 可以浏览并编辑合成项目文件 | 浏览器编辑、文件切换测试 |
| SW-03 | Agent 建议和拟议差异明确标记为模拟；学生可接受、拒绝或自行接管 | 浏览器交互及结果 |
| SW-04 | 无代码执行、Shell、依赖安装、联网工具入口；运行控件禁用 | DOM/静态检查与浏览器状态 |
| SW-05 | 提交需填写任务相关验证/解释；不把对话单独作为成果 | 浏览器表单验证与状态 |
| SW-06 | 刷新清空、后端/真实 Agent 未接入的事实明确 | 页面状态与报告 |
| SW-07 | 语法、教师端/全量回归、浏览器 QA 通过 | 命令结果与 Artifact |

## 停止条件

一旦需要真实模型/密钥/第三方数据传输、登录、真实学生或材料、持久存储、代码执行/文件工具、后端联调、ECS、部署、用户招募或研究数据，停止对应扩展并先建立所需 Gate/决策。前端原型不能声称学生真正使用了 Agent。
