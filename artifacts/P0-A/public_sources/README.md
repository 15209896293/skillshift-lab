# P0-A Public Source Register

## Purpose

This folder records publicly searchable materials used to prepare the P0-A traditional task inventory.

These sources are not automatically treated as real local historical classroom tasks.

They are used as:

- candidate task inspiration,
- public baseline examples,
- course capability references,
- evidence for common Big Data Technology training themes.

## Source Boundary

Each record must label the source type:

- Public practical training case
- Course standard
- Training guide
- Teaching resource
- Competition or exercise material
- Unknown / needs verification

## Current Source Notes

The first public-source pass uses web-searchable materials around:

- SQL / MySQL database tasks,
- Linux service and environment tasks,
- Hadoop / HDFS tasks,
- Spark tasks,
- Python data cleaning and analysis,
- visualization and report tasks.

Do not call these "school historical tasks" unless the product owner later confirms they came from real local teaching materials.
