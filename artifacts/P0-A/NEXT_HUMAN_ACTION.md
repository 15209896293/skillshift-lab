# P0-A Next Human Action

## What The Product Owner Should Provide

If possible, provide 3 to 5 real traditional training tasks from school or teacher materials.

Acceptable forms:

- Word document,
- PDF,
- PPT,
- Excel,
- screenshot,
- copied task text,
- textbook exercise,
- teacher assignment message,
- student training guide.

## Where To Put Them

Put raw materials here:

`artifacts/P0-A/raw_tasks/`

If the folder does not exist, create it.

## What To Include For Each Task

Best case:

- task title,
- original instructions,
- required data,
- expected output,
- scoring standard,
- software environment,
- estimated class time.

Minimum acceptable:

- task title,
- screenshot or copied task text,
- any clue about environment or expected result.

## If No Local Materials Are Available Yet

Use `artifacts/P0-A/task_inventory_public_seed.md` as the starting public-source candidate list.

Do not describe it as local school evidence.
